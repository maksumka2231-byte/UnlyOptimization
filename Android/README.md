# 📱 UnlyOptimization - Android приложение

## ✅ Функции

- ✅ **Мониторинг пинга** - Измерение пинга в реальном времени
- ✅ **Скорость интернета** - Определение текущей скорости соединения
- ✅ **Оптимизация сети** - Оптимизация параметров Android
- ✅ **Активация кодов** - Ввод одноразовых кодов активации (150 кодов)
- ✅ **Профили игр** - Сохранение настроек для разных игр
- ✅ **Статистика** - История показателей сети
- ✅ **Темный интерфейс** - Красивый и удобный UI

## 🛠️ Используемые технологии

- **Kotlin** - Основной язык разработки
- **Jetpack Compose** - UI разработка
- **Coroutines** - Асинхронное программирование
- **Retrofit** - HTTP клиент
- **DataStore** - Локальное хранилище
- **Material Design 3** - Дизайн

## 🚀 Установка

### Требования
- Android Studio Arctic Fox или выше
- Android SDK 24+ (для компиляции)
- Gradle 7.0+

### Шаги установки

1. **Откройте проект в Android Studio**
   ```bash
   cd Android
   ```

2. **Синхронизируйте Gradle**
   - Android Studio автоматически синхронизирует проект
   - Дождитесь завершения синхронизации

3. **Запустите приложение**
   - Нажмите Run (Shift + F10)
   - Выберите эмулятор или физическое устройство

## 📋 Разрешения

Приложение требует следующие разрешения:
- `INTERNET` - Доступ в интернет
- `ACCESS_NETWORK_STATE` - Информация о сети
- `CHANGE_NETWORK_STATE` - Изменение параметров сети

## 🎮 Использование

### Активация
1. Получите код активации (всего 150 кодов)
2. Откройте приложение
3. Введите код в поле "Активация кода"
4. Нажмите "✅ Активировать"
5. Получите подтверждение в Telegram (@unlymng)

### Оптимизация
1. Нажмите "⚙️ Оптимизировать сеть"
2. Дождитесь завершения процесса
3. Посмотрите улучшение пинга в реальном времени

### Статистика
1. Нажмите "📊 Статистика"
2. Посмотрите историю показателей
3. Сравните с предыдущими измерениями

## 🔐 Безопасность

- Коды хранятся на защищенном сервере
- Каждый код может использоваться только один раз
- История активации отслеживается
- Все данные пользователя зашифрованы

## 🐛 Troubleshooting

### Приложение не может измерить пинг
- Проверьте интернет соединение
- Убедитесь, что разрешение INTERNET дано
- Перезагрузите приложение

### Код активации не работает
- Проверьте правильность ввода кода
- Убедитесь, что код еще не был использован
- Проверьте соединение с сервером

### Оптимизация не работает
- Некоторые функции требуют прав администратора
- Установите приложение как системное (требуется рут)
- Используйте ADB команды для оптимизации
