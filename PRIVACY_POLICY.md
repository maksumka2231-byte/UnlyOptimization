# Privacy Policy - Unly Optimization

## Политика Конфиденциальности

### 1. Введение

Unly Optimization (далее "Приложение") уважает вашу конфиденциальность. Данная политика объясняет, как мы собираем, используем и защищаем ваши данные.

### 2. Собираемые данные

**Приложение НЕ собирает и НЕ отправляет следующие данные:**
- Личную информацию (имя, адрес, телефон)
- Данные о контактах
- Геолокацию
- История браузера
- Содержимое приложений

**Приложение собирает только:**
- Настройки приложения (язык, автобуст)
- Коды активации (локально сохраняются)
- Системные параметры для мониторинга (CPU, RAM, температура, FPS, пинг) - **только для отображения в приложении**

### 3. Использование данных

Все собираемые данные используются **исключительно для функционирования приложения** на вашем устройстве:
- Отображение показателей производительности
- Сохранение ваших предпочтений
- Активация приложения

### 4. Хранение данных

- Все данные хранятся **локально** на вашем устройстве
- Данные **не отправляются** на серверы
- Вы можете удалить все данные приложения через настройки Android

### 5. Безопасность

- Приложение использует шифрование DataStore для хранения конфиденциальных данных
- Приложение не содержит вредоносного кода
- Регулярно обновляется для исправления уязвимостей

### 6. Разрешения

Приложение запрашивает разрешения для следующего:

| Разрешение | Назначение |
|-----------|----------|
| SYSTEM_ALERT_WINDOW | Вывод оверлея на экран |
| PACKAGE_USAGE_STATS | Мониторинг использования приложений |
| BIND_ACCESSIBILITY_SERVICE | Автоматический буст при запуске игр |
| WRITE_SETTINGS | Отключение автояркости и синхронизации |
| INTERNET | Проверка пинга |
| MODIFY_AUDIO_SETTINGS | Оптимизация звука для игр |

### 7. Изменения политики

Мы может обновить данную политику в любой момент. Продолжение использования приложения означает согласие с изменениями.
