# UnlyOptimization - Техническая документация

## 📋 Система кодов активации (150 одноразовых)

### Принцип работы:
1. **Каждый код уникален** и может использоваться только один раз
2. **Навсегда привязывается** к пользователю при активации
3. **Невозможно переиспользовать** - система проверяет статус `used`
4. **Отслеживается история** - дата и время активации, пользователь

### Структура кода (JSON):
```json
{
  "code": "ABC12345",
  "used": false,
  "used_by": "username",
  "used_date": "2024-01-15T10:30:00",
  "created_date": "2024-01-01T00:00:00"
}
```

## 🌐 API Endpoints

### Коды активации
- `POST /api/codes/activate` - Активировать код
- `GET /api/codes/check/{code}` - Проверить статус кода
- `GET /api/codes/statistics` - Получить статистику

### Сеть
- `GET /api/network/ping` - Измерить пинг
- `GET /api/network/speed` - Измерить скорость

### Профили
- `POST /api/profiles/create` - Создать профиль
- `GET /api/profiles/list` - Список профилей

## 🛠️ Установка

### Windows приложение
```bash
cd Windows
# Откройте UnlyOptimization.sln в Visual Studio
# Установите NuGet пакеты
# Скомпилируйте и запустите
```

### Android приложение
```bash
cd Android
# Откройте в Android Studio
# Синхронизируйте Gradle
# Запустите на устройстве
```

### Backend сервер
```bash
cd Server
pip install -r requirements.txt
python api.py
# API доступен на http://localhost:8000
```

## 🔐 Безопасность

- Коды хранятся в `ActivationCodes/codes.json`
- Каждый код - 8 символов (буквы + цифры)
- История активации сохраняется
- Telegram токен нужно установить в конфиге
